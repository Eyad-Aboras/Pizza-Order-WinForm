# Pizza Ordering System - WinForms

A desktop pizza ordering application built using C# and Windows Forms.

## Features

- Choose pizza size
- Choose crust type
- Add/remove toppings
- Automatic total price calculation
- Order summary
- Reset order
- Disable controls after confirming order

## Technologies Used

- C#
- .NET Framework
- Windows Forms

## Concepts Practiced

- Event Handling
- Methods & Functions
- UI Design
- Separation of Concerns
- Dynamic Price Calculation
